# Customer-Churn-Analysis-project

# Customer Churn Analysis

# Project Overview
This project focuses on analyzing customer churn data using Python, SQL, Pandas, and SQLite. The objective is to clean customer data, explore subscription and support information, and identify useful insights related to customer churn.

# Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL
- SQLite
- Jupyter Notebook
- Excel and CSV

# Project Tasks
- Import data from a database
- Clean and standardize customer data
- Handle missing values
- Convert columns to appropriate data types
- Analyze customer subscription information
- Explore customer support data
- Perform data analysis using Python and SQL

# Project Files
- `churn_analysis.ipynb` — Analysis notebook
- `customer_churn_data_raw.xlsx` — Raw dataset
- `exported_churn_data.csv` — Exported dataset
- `customer_churn.db` — SQLite database used by the project

# How to Run
1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries: `pandas`, `numpy`, `matplotlib`, and `seaborn`.
4. Open `churn_analysis.ipynb`.
5. Run the notebook cells in order.

# Learning Outcomes
This project provides practical experience in data cleaning, SQL, Python-based analysis, and working with structured datasets.
